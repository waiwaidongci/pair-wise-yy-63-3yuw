# pair-wise-yy-63 跨产品设计令牌治理与主题发布平台

维护基础令牌、语义令牌和组件别名，支持品牌主题、明暗模式与平台变体继承覆盖。包含令牌树、Monaco JSON 编辑、依赖图、循环引用与对比度校验、批量替换、变更评审、版本差异和发布锁定。

## 颜色令牌下线迁移（`/migration`）

- **登记**：维护员登记「待下线旧令牌 / 替代令牌 / 迁移范围（产品）」，按批次提交。
- **引用链影响面**：基础色 → 语义令牌 → 组件别名 → 产品根引用逐级解析，自动算出每个主题受影响的产品（区分范围内/范围外）。
- **门禁分流**：替代关系缺环、类型不一致（非颜色令牌替代颜色）、对比度不达标（文字 4.5:1 / 控件 3:1）的条目暂停，只保留可处理项写入。
- **并发仲裁**：两个标签页对同一旧令牌提交范围重叠的映射时，先落定映射生效，后到内容按旧引用保留并登记「待确认」；通过 `BroadcastChannel` 同步其他标签页的落定结果。
- **事务写入与快照恢复**：写入中途失败时从上一个完整发布快照恢复令牌树与产品改写，登记保留为「待分析」可重试；快照支持手动恢复。
- **旧稿兼容**：旧稿没有替代关系的令牌按原始字面量兼容读取，不阻断渲染。
- **可视化**：令牌树（旧引用/已完成/待确认产品）、依赖图（普通/已改写/旧引用三种边）、产品 × 主题迁移矩阵与发布门禁一目了然。
- 演示按钮：`登记示例批次`（含三种暂停原因）、`模拟两个标签页并发`、`故障注入`（触发失败回滚）、`重置演示`。

## 技术栈

Vue 3、TDesign、Pinia、Vue Router、TanStack Query、Axios、Monaco Editor、Vite、TypeScript。

## 运行

```bash
npm install
npm run dev
```

访问 `http://localhost:62063`。草稿、变更评审和当前主题保存在 `localStorage`。

```bash
npm run build
```
